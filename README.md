# TestProject

A simple C# project for testing ReviewCheck MVP-2.

## Structure

- `src/TestProject/` - Main console application
  - `Program.cs` - Entry point
  - `Calculator.cs` - Calculator interface definition
  - `SimpleCalculator.cs` - Calculator implementation
  - `Config.cs` - Configuration module

## Building

```bash
dotnet build
```

## Running

```bash
dotnet run --project src/TestProject/TestProject.csproj
```

## Testing with ReviewCheck

1. Make changes to any of the C# files
2. Open ReviewCheck in Claude Code
3. Follow the guided review to understand the changes
